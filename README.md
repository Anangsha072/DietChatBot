HealthiClick Bot – AI Diet Chat Application

HealthiClick Bot is a full-stack AI-powered chat application that helps users get personalized diet guidance. Users can log in with Google and ask diet-related questions, receiving answers generated by a large language model (Google Gemini) that references a curated database of 50 FAQs.

Key Features

🟢 Google Authentication via Clerk

🟢 AI-powered responses referencing verified diet FAQs

🟢 Conversation history for seamless chat experience

🟢 Modern, responsive UI built with React and Tailwind CSS

🟢 FAQ database with ready-made diet Q&A

How It Works

User Interaction: Users ask diet-related questions via a chat interface.

LLM Processing: The question is sent to the backend, where Google Gemini AI generates a context-aware answer.

FAQ Reference: Answers are enhanced with references to the preloaded FAQ database for reliability.

Response Delivery: Users receive the AI response with relevant references in real-time.

Project Structure (Overview)
Healthiclick-Bot/
├── Client/   → React + Vite frontend (UI & chat interface)
└── server/   → Node.js + Express backend (API, AI integration, FAQ database)

Technology Stack

Frontend: React, Vite, Tailwind CSS, Clerk (Google OAuth)

Backend: Node.js, Express, MongoDB, Google Gemini AI
